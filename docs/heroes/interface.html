System Architecture

The QPLANT cryogenic helium system interfaces with the MYRRHA proton beam facility. Helium serves as the primary coolant for superconducting magnets and beam targets. The system boundary encompasses:

  • Cold box — Cryogenic distribution at 4K-80K
  • Warm distribution — Gas handling at 273K-373K
  • Recovery system — Helium recapture and purification
  • Interface points — Terminal connections per QPLANT_Interface doc
