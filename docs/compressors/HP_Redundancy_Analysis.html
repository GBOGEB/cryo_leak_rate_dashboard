Reliability & Availability Comparison

Formulas

Single unit: A = MTBF / (MTBF + MTTR) = 8760 / (8760 + 8) = 99.91% k-of-M system: A_sys = Σ(i=k..M) C(M,i) × A^i × (1-A)^(M-i) 2-of-3: A_sys = A²(3 − 2A) = 99.9997% 3-of-4: A_sys = A³(4 − 3A) = 99.9995% 2-of-4: A_sys = 6A⁴ − 8A³ + 3A² (via binomial) → ~100% 1-of-2: A_sys = 2A − A² = 99.9999%
