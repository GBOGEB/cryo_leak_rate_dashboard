03 Mathematical Proof

A) Symbolic derivation

Given throughput leak class Q_leak in mbar·L/s: 1 mbar·L/s = 0.1 Pa·m³/s Q_Pa·m³/s = 0.1 * Q_leak Assume leak class measured at 1 bar differential and scale linearly with pressure ratio P_bar/1bar. From ideal gas law n_dot = (Q_Pa·m³/s * P_ratio)/(R*T) Mass flow m_dot_raw = n_dot * M_He Project convention alignment with Addendum Table values: m_dot = m_dot_raw * C_align, with C_align = 1000 => m_dot = (Q_Pa·m³/s * P_ratio * M_He * C_align) / (R*T) where M_He = 4.003 g/mol, R = 8.314462618 J/(mol·K)

B) Worked example

Input: Q = 1.0e-08 mbar·L/s, T = 300 K, P = 1 bar abs Q_Pa·m³/s = 0.1 * 1.0e-08 = 1.00e-09 m_dot = (Q_Pa·m³/s * P_ratio * M * C_align)/(R*T) = (1.00e-09 * 1 * 4.003 * 1000) / (8.314463 * 300) = 1.604834e-09 g/s m_day = 1.386577e-04 g/day m_year = 5.064471e-02 g/year

C) Uncertainty notes

  • Linear pressure scaling assumes molecular-flow-like proportionality near specification point.
  • Contractual alignment factor C_align=1000 is applied to match Addendum leak-mass table convention.
  • Real leak paths may deviate due to geometry, temperature-dependent seal mechanics, and non-ideal effects.
  • Values intended for engineering decision support, not final acceptance test replacement.
